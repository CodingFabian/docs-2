$TIMESCALE_DB is an open-source [PostgreSQL extension][extension] designed for running real-time analytics on rapidly growing time-series and event data. It is engineered up from PostgreSQL and maintains full SQL support.

Best practice is to run $TIMESCALE_DB in a [$SERVICE_LONG](https://console.cloud.timescale.com/signup), but you can also install and host $TIMESCALE_DB yourself.

[extension]: https://www.postgresql.org/docs/current/external-extensions.html
